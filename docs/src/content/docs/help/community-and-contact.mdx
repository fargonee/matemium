## Where should I go?

- **Watch and share:** YouTube and Instagram
- **Follow releases or contribute:** GitHub
- **Receive announcements:** Telegram
- **Discuss the project:** Reddit, X, and Bluesky
- **Read engineering stories:** DEV Community
- **Follow launch milestones:** Product Hunt
- **Talk privately:** [matemiumm@gmail.com](mailto:matemiumm@gmail.com)

For reproducible bugs and feature proposals, prefer
[GitHub Issues](https://github.com/fargonee/matemium/issues) so the discussion
can stay connected to source and fixes.
