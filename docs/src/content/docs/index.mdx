Matemium begins with the structure of an explanation—not a conventional video
timeline and not a single prompt. Describe the idea, choose a production path,
shape it with the agent, render locally, inspect the evidence, and deliver the result.

<CardGrid stagger>
	<Card title="Use the desktop studio" icon="setting">
		Install Matemium, create a project, work through its roadmap, render, repair,
		and export without learning the engine internals first.

		[Start with the desktop →](/start/install/)
	</Card>
	<Card title="Author visual scenes" icon="pencil">
		Learn `scenes.py`, `CanvasBuilder`, infinite tapes, layout, camera movement,

</CardGrid>

## Follow the complete production journey

<CardGrid>
	<Card title="1 · Describe" icon="comment">
		Establish the subject, audience, purpose, and intended understanding.
	</Card>
	<Card title="2 · Choose a path" icon="random">
		Create a visual-first film, synthesize narration, or work around a custom voice.
	</Card>
	<Card title="3 · Shape with the agent" icon="robot">
		Resolve meaningful creative decisions before scene generation begins.
	</Card>
	<Card title="4 · Render and repair" icon="rocket">
		Render on your machine, inspect visual evidence, and correct problems in context.
	</Card>
	<Card title="5 · Deliver" icon="approve-check">
		Export portrait reels, landscape lessons, or complete static reasoning sheets.
	</Card>
</CardGrid>

## Learn from real projects

The recipe library explains projects that actually render in Matemium. Each recipe
connects the finished result to its real authoring source.

- [Compare quadratic graphs](/recipes/mathematics/quadratic-graphs/)
- [Explain electromagnetic waves](/recipes/physics/electromagnetic-waves/)

More recipes are being developed across chemistry, computing, engineering, economics,
biology, history, philosophy, language learning, and general education.
