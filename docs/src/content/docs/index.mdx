## What the desktop includes now

- Durable project workspaces with source, helpers, production briefs, media, and output history
- Eleven bundled cross-subject examples that open as editable copies
- Four accepted flagship outcomes across physics, chemistry, biology, and engineering
- Portrait and landscape local rendering plus live replay preview
- Camera-facing multi-tape composition and explicit tape scrolling
- Sampled paths and plots, semantic diagrams, state transitions, and compiled morphs
- Persistent 3D worlds and camera inspection alongside analytical tape contexts
- Full-tape PNG/PDF documents and complete project archive import/export
- External bring-your-own-provider models or compatible local models

## Learn from real projects

The recipe library explains projects that actually render in Matemium. Each recipe
connects the finished result to its real authoring source.

- [Compare quadratic graphs](/recipes/mathematics/quadratic-graphs/)
- [Explain electromagnetic waves](/recipes/physics/electromagnetic-waves/)

The bundled source library also spans Fourier visualization, orbital mechanics,
chemistry, graph algorithms, control engineering, economics, biology, history,
philosophy, language learning, and municipal water systems.
