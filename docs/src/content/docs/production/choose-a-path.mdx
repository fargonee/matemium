---
title: Choose a production path
description: Select visual-first, voice synthesis, or custom voice for a Matemium project.
---

The production path determines the order in which content, timing, authoring,
audio, rendering, and validation happen. Choose it deliberately in the project
passport.

## Visual-first

Choose this when the mathematical or explanatory film should be complete without
a final voice track.

Typical journey:

```text
Tape content → Orchestration → Scene authoring
→ Render and visual repair → Mute delivery
```

Best for:

- Reels that will receive music or sound later
- Silent classroom visuals
- Experiments focused on visual language
- The fastest route to a validated animation

The result can still receive audio in an external editor.

## Voice synthesis

Choose this when Matemium should develop narration and generate synthetic speech.

Typical journey:

```text
Tape content → Orchestration
→ Narration and provisional timing
→ Scene authoring → Render and repair
→ Final timing regulation → TTS generation
→ Final assembly
```

Best for:

- End-to-end narrated explanations
- Projects where script and visual timing can be designed together
- Repeatable voice generation

Do not generate final speech too early. Visual repair can change timing, so the
final voice should be produced after the validated render has stabilized.

## Custom voice

Choose this when an approved human or external performance should control the
clock.

Typical journey:

```text
Audio specification → Audio generation or recording
→ Transcription and validation
→ Content reconciliation → Scene authoring
→ Render and synchronization repair → Final assembly
```

Best for:

- A teacher or creator’s own performance
- Interviews or supplied narration
- Projects where emphasis, pauses, and personality are central

The audio must be validated before visuals are authored against it. A transcript
that does not match the approved recording will produce synchronization errors.

## Comparison

| Question | Visual-first | Voice synthesis | Custom voice |
| --- | --- | --- | --- |
| Fastest first render | Yes | No | No |
| Final narration generated by workflow | No | Yes | No |
| Human performance controls timing | No | No | Yes |
| Timing can change during early visual repair | Freely | Provisionally | Carefully |
| Requires audio validation | No | Yes | Yes |

## Changing paths

A path change can invalidate downstream artifacts. If you change after authoring
has started:

1. Update the passport.
2. Let the roadmap rebuild the branch.
3. Review invalidated phases.
4. Reconcile content, timing, and source deliberately.

Do not simply rename the path while retaining incompatible later artifacts.
