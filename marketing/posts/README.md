# Communication and social drafts

This directory contains working drafts for launch communication and platform-specific social posts. It is repository-only planning material: these files are not canonical product documentation and are not included in the Matemium website build.

Before publishing anything from here, check every factual product claim against the current source code and documentation. Adapt each post to the norms, audience, length, and tone of its community rather than copying one version verbatim across platforms.

Use the matching subdirectory for each destination. Cross-platform launch planning that is not yet adapted for a specific community belongs in `launch/`.
