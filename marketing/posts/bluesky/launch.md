## Compact launch post

I’m releasing Matemium: a local-first, source-available desktop compiler for visual explanations, built on Manim. It is early on purpose—I want real projects to expose the weak parts and people who care about the problem to shape what comes next.

## Thread

### 1/5

Matemium started as a way to keep technical animation code focused on the explanation. You author visible Python project files; the compiler handles layout, persistent visual state, camera actions, and the path to a local Manim render.

### 2/5

Its main surface is an infinite reasoning tape, where earlier equations and diagrams can stay spatially present. There is also a separate 3D world. Tapes remain clean, camera-facing contexts instead of becoming tiny panels floating in space.

### 3/5

I’m interested in AI as a careful project coworker, not a magic “make video” box. It can work on inspectable source and briefs, while checks and rendering stay local. Reliable autonomy and visual verification still need real engineering.

### 4/5

The code is available to inspect and contribute to under Matemium’s source-available license. That is not the same as open source: redistribution and competing public builds are restricted. The software is free to use within the license.

### 5/5

I’m opening the door before every edge is sanded down: setup prerequisites, signing, rough workflows, and all. If you like developer tools, visual explanations, local software, or testing ambitious abstractions, I’d value your feedback.
