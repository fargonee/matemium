# Matemium 0.3.0 — first public desktop launch

Matemium is a free, source-available desktop studio and layout-to-animation compiler for structured visual explanations, built on Manim Community Edition.

This release makes the current desktop and compiler available for early public use. It is intended for people willing to test real projects, report rough edges, and help improve the official project.

## Highlights

- Python `scenes.py` authoring through `CanvasBuilder` and `CanvasScene`
- Infinite reasoning tape with persistent visual identities and camera movement
- Separate free 3D world plus isolated camera-facing tapes
- Generic `DataPath`, `DataPlot`, and `Diagram` visuals
- Semantic state transitions, registered morphs, project checks, and local rendering
- 9:16 and 16:9 profiles, full-sheet export, and reel-cutting tools
- Tauri desktop workspaces with code editing, AI assistance, preview/render workflows, project archives, and examples
- Native release targets for Linux x86_64, Windows x86_64, Apple Silicon macOS, and Intel macOS

## Before installing

Rendering requires host-installed FFmpeg and LaTeX. Windows packages are unsigned until signing is configured; macOS builds may require approval in Privacy & Security when notarization credentials are unavailable. Automatic updates are not enabled.

The example library contains authoring proofs at different review stages, not eleven final showcase masters. The verification-gated autonomous production runtime is also ongoing work.

Matemium is source-available, not open-source. Review the Matemium Source-Available License before use or modification.
