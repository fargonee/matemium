# Matemium is now available for early public use

Matemium is a free, source-available desktop studio and local layout-to-animation compiler for structured visual explanations. The current launch includes the working compiler, desktop project workflow, local Manim rendering, and native build targets—but it is still early, and outside installation reports, render failures, API criticism, and contributions are explicitly welcome.

- Release and downloads: [DOWNLOAD_URL]
- What Matemium is and why it is launching now: [WEBSITE_URL]/articles/introducing-matemium
- How to contribute: [GITHUB_URL]/blob/main/CONTRIBUTING.md

Rendering requires host-installed FFmpeg and LaTeX. Matemium is source-available, not open-source; review the license before use or modification.
