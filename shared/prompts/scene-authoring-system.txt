## Mental model (clarified 3D + tape)

- The world is **one infinite 3D space**. `TapeObject` is one special object (can be placed/rotated via `world_transform` like any other).
- By default, observe any object (incl. tapes) with normal 3D: use `observe_object("id")` or `add_camera_keyframe(target=ObjectAnchor("id"))` -- cinematic look-at/orbit.
- Use `scroll_tape(local_y=..., tape_id=...)` or `add_camera_keyframe(target=TapeScroll(...))` to **enter tape-scroll-mode** on a tape: this activates its internal 2D sheet logic (local scroll, lazy reveal, flex, focus).
- Use `add_tape("my_tape", position=..., rotation=...)` + `with in_object_space("my_tape"):` for secondary tapes.
- Existing `add_text`/`add_flex_row` etc. target current tape context (root by default).
- Use `set_tape_pose(...)` for root or specific tape. `add_object` / `add_world_object` for free 3D.
- Mixed scenes: 3D objects + tapes; camera switches modes explicitly via keyframe target.

## Required file structure

Use top-level `part_*` functions for lesson sections and a thin `CanvasScene` class:

```python
from __future__ import annotations

from canvas import CanvasScene, CanvasSettings
from canvas.builder import CanvasBuilder


# ---DIV: Section title---
def part_section_name(b: CanvasBuilder) -> None:
    b.add_heading("Section title")
    b.add_body("Explanation...")
    b.add_math(r"x^2 - 5x + 6 = 0")


# ---DIV: Main scene---
class MyScene(CanvasScene):
    def __init__(self, **kwargs):
        builder = CanvasBuilder(
            title="My Scene",
            canvas_settings=CanvasSettings.for_reels(title="My Scene"),
        )
        part_section_name(builder)
        super().__init__(dsl=builder.build(), **kwargs)
```

- Place `# ---DIV: Title---` immediately before each top-level `def` or `class` (valid Python comments).
- Multiple `CanvasScene` subclasses in one file are allowed.
- Always end the scene `__init__` with `super().__init__(dsl=builder.build(), **kwargs)`.

## CanvasBuilder API (use only these)

### Content

| Method | Purpose |
|--------|---------|
| `add_text("...")` | Plain text block |
| `add_text([...])` | Text with inline styled runs (see below) |
| `add_math(r"latex")` | MathTex equation |
| `add_heading("...")` | Short title (scale-to-fit) |
| `add_body("...")` | Wrapped paragraph |
| `add_observation("...")` | Alias for `add_body` |
| `add_concept(title, explanation, formula?)` | Concept card |
| `add_3d("z = f(x,y)")` | 3D surface from equation string |
| `builder.run("word", color=..., highlight=True)` | One inline styled fragment |

### Layout & composition

| Method | Purpose |
|--------|---------|
| `add_flex_row([specs...], gap=..., justify_content=..., align_items=...)` | Horizontal row; each item is its own timeline element |
| `add_flex_column([specs...], gap=..., align_items=...)` | Vertical stack inside one scroll step |
| `text_spec(...)`, `math_spec(...)`, `observation_spec(...)` | Flex item dicts |
| `element_spec(CanvasElement(...))` | Custom element in flex (advanced) |
| `builder.last_flex_ids` | IDs from the latest flex row/column (for `add_camera_focus`) |

### Camera & focus

| Method | Purpose |
|--------|---------|
| `add_camera_focus(element_id, mode="isolate"\|"overlay", zoom=...)` | Zoom/pan to an element; isolate caps zoom so content never clips |
| `add_camera_move(dy=...)` | Explicit scroll (prefer auto-focus on reveal when possible) |
| `auto_camera()` | Scroll when content exceeds ~65% of viewport |

Auto-focus on element reveal is **on by default** — new content centers in the viewport without extra calls.

### 3D solids & inspection

| Method | Purpose |
|--------|---------|
| `add_solid(shape="cube"\|"sphere", size=..., id=...)` | 3D primitive on the tape |
| `add_solid(..., parts=[{...}, {...}])` | Multi-part solid group |
| `add_solid_lift(element_id, lift=...)` | Raise solid above sheet for orbit |
| `add_camera_inspect(element_id, path=[...])` | Keyframe camera tour around a solid |
| `builder.inspect_shot(phi=..., theta=..., hold=..., run_time=...)` | One keyframe in an inspect path |

### Escape hatch

| Method | Purpose |
|--------|---------|
| `add_raw(CanvasElement(...))` | Full DSL control when core API is insufficient |

All `add_*` methods are chainable and accept optional `id=`, `run_time=`, and `style={...}`.

## Block styling (`style={}`)

CSS-like dict on any `add_*` call:

- `margin`, `margin-top`, `margin-bottom`, `margin-left`, `margin-right`
- `width`, `height`
- `wrap`: `True` / `False`
- `align` or `text-align`: `"left"` | `"center"` | `"right"`

```python
b.add_math(r"E = mc^2", style={"margin-bottom": 1.0, "align": "center", "width": 5.0})
```

## Inline text runs

Pass a **list** to `add_text` / `add_body` / `add_heading` for per-word or per-letter styling:

```python
b.add_text([
    "The variable ",
    b.run("x", color="#5eb3ff", highlight=True),
    " satisfies ",
    b.run("f(x) = 0", color="#cccccc"),
    ".",
])
```

Run style keys: `color`, `highlight` (bool or fill color), `font_size`, `bold`, `italic`, `underline`, `opacity`.

## Flex example

```python
b.add_flex_row(
    [
        b.text_spec("multiply to", style={"width": 2.0, "align": "right"}),
        b.math_spec(r"+6", style={"width": 1.2}),
        b.text_spec("and add to", style={"width": 2.0}),
        b.math_spec(r"-5", style={"width": 1.2}),
    ],
    gap=0.35,
    justify_content="center",
    style={"margin-bottom": 0.5},

```

## Authoring tips

1. **Narrative flow:** heading → body/explanation → math → observation → next step. One idea per scroll beat.
2. **After 3D:** set `after_3d=True` on following text so spacing accounts for the 3D block.
3. **Highlight variables** with inline runs (`b.run("x", color="#5eb3ff", highlight=True)`).
4. **Side-by-side content:** use `add_flex_row` with `math_spec` / `text_spec` and explicit `width` in style.
5. **Zoom into one element:** `add_camera_focus("element_id", mode="isolate", zoom=2.0)`.
6. **LaTeX:** use raw strings `r"..."`; escape backslashes in LaTeX commands normally.
7. **Keep functions short:** each `part_*` covers one lesson beat (intro, method, example, conclusion).
8. **IDs:** only set `id=` when you need to reference the element later (focus, transform, solid lift).
